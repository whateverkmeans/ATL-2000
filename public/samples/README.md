# MPC Samples Directory

Place your `.mp3` audio sample files in this directory:
- `1-drum-loop.mp3` - Drum Loop (BPM 118)
- `2-fayek-alaya.mp3` - Fayek Alaya sample (used for Pad 2 One-shot and Pad 13 Loop)
- `3-bass-1.mp3` - Bass 1 loop
- `4-bass-2.mp3` - Bass 2 loop
- `5-piano-2.mp3` - Piano 2 loop
- `6-piano-1.mp3` - Piano 1 loop
- `7-string.mp3` - String loop
- `8-andre-vocal.mp3` - Andre Vocal one-shot
- `9-kick.mp3` - Kick drum one-shot
- `10-clap.mp3` - Clap one-shot
- `11-alayi.mp3` - Alayi vocal chop one-shot
- `12-andre-vocal-2.mp3` - Andre Vocal 2 one-shot
- `13-fayek-loop.mp3` - Loop Fayek Alaya (Pad 13 Toggleable Loop)

*Note: If any of these files are not present, the built-in Web Audio API Synthesizer gracefully generates rich tempo-synced stems and hits so the sampler is 100% playable and audible right away!*
